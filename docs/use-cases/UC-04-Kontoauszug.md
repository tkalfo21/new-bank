# UC-04 – Kontoauszug erhalten

## Name
Kontoauszug erhalten

## Kurzbeschreibung
Ein Kunde möchte einen Kontoauszug zu seinem Konto erhalten.

## Akteure
- Kunde
- Bankmitarbeiter

## Auslöser
Der Kunde fordert einen Kontoauszug an.

## Ergebnisse
Der Kunde erhält einen Kontoauszug.

## Vorbedingung
Der Kunde besitzt ein Konto.

## Nachbedingung
Der Kontoauszug wurde erstellt und dem Kunden übergeben.

## Eingehende Daten
- Kontonummer

## Essenzieller Ablauf
1. Kunde fordert einen Kontoauszug an.
2. Kunde nennt sein Konto.
3. Bankmitarbeiter ruft die Kontodaten ab.
4. Kontoauszug wird erstellt.
5. Kunde erhält den Kontoauszug.
