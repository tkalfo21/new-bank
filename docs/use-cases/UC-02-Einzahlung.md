# UC-02 – Einzahlung tätigen

## Name
Einzahlung tätigen

## Kurzbeschreibung
Ein Kunde zahlt Geld auf sein Konto ein.

## Akteure
- Kunde
- Bankmitarbeiter

## Auslöser
Der Kunde möchte Geld einzahlen.

## Ergebnisse
Der Kontostand wurde erhöht.

## Vorbedingung
Der Kunde besitzt ein Konto.

## Nachbedingung
Der eingezahlte Betrag wurde dem Konto gutgeschrieben.

## Eingehende Daten
- Kontonummer
- Einzahlungsbetrag

## Essenzieller Ablauf
1. Kunde nennt sein Konto.
2. Kunde gibt den Einzahlungsbetrag an.
3. Bankmitarbeiter verbucht die Einzahlung.
4. Der Kontostand wird erhöht.
